## 0.1.0

A trusted library of verified and referenced hydrometeorological calculations and derivations.

This release establishes the project scaffold.

### Typing

- The `.pyi` stubs describing each calculation's accepted input types are now generated from the module's own
  signatures by `make stubs` (also run as part of `make qa`), rather than written and maintained by hand.
- The stubs declare one overload per input kind, expression first. Mixing kinds in a call is a type error as
  well as the runtime `TypeError` dispatch already raised.
- `tests/hydrometlib/test_overloads.py` fails if a committed stub no longer matches its module, so a stub can no
  longer drift from the code it describes; `tests/hydrometlib/test_type_inference.py` checks the declarations
  infer the types they promise.

### Calculations

- Site attributes now accept either a number or a column. Quantities such as `measured_height`,
  `wilting_point`, `altitude`, `latitude` and the COSMOS calibration set are annotated `Attribute` and take
  the single value they usually are, or a column when a frame covers several sites with their attributes
  joined on. `wind_speed_height_correction(ws, 10.0)` and `mean_sea_level_pressure(pa, ta, altitude_column)`
  both previously raised `TypeError`.
- Giving *every* column argument as a number evaluates the calculation for that one set of values and returns
  a plain Python number, rather than an expression - `net_radiation(100.0, 20.0, 300.0, 350.0)` is `30.0`. The
  result is `None` where a calculation yields null by design, so the declared return is `float | None`.
- Numbers still cannot be mixed into real data columns; the error now says which parameter is a data column
  and how to evaluate for a single set of values instead.

### What's in the scaffold

- `src/hydrometlib/` package with `__init__` and `__main__`
- Tests with pytest and coverage (90% threshold)
- CI via GitHub Actions (NERC-CEH/dri-cicd reusable workflows)
- Docs site with Sphinx + Shibuya theme, auto-deployed to GitHub Pages
- `Makefile` with dev commands: qa, test, type-check, bump, release
- Pre-commit git hook for ruff format and lint
- Contributing guide, code of conduct
- .editorconfig, .gitignore
