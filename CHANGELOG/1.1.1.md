# 1.1.1

A patch release with no library changes. This is the first release of `hydrometlib` on [PyPI](https://pypi.org/project/hydrometlib/).

## Installation

- `pip install hydrometlib` or `uv add hydrometlib`.
- For pandas or NumPy inputs, install the matching extra: `pip install "hydrometlib[pandas]"` or
`pip install "hydrometlib[numpy]"`.

## Packaging

- Releases are now published to PyPI automatically when a release is merged into `main`, using trusted publishing.
- Added keywords and classifiers to the package metadata, including supported Python versions (3.12 and 3.13) and
`Typing :: Typed`.

## Documentation

- The installation guide now installs from PyPI rather than from GitHub.
- The README has an overview of the library, an installation section and a PyPI badge, and its links now work on PyPI.
